# 3-Match Puzzle Map Tool

제작: [sungmin2ee](https://github.com/sungmin2ee)

Cave 하나를 퍼즐 레벨 하나로 편집하는 브라우저 기반 맵툴입니다.

[▶ 맵툴 실행하기](https://sungmin2ee.github.io/windy-cave-map-tool-public/)

## 사용법

맵툴 상단의 **사용법**에서도 아래 내용을 볼 수 있습니다.

### 시작하기

- 기존 맵은 상단의 **JSON 가져오기**로 엽니다. 미리보기에서 레벨 수, 맵 크기, 특수 피스 종류, 읽지 못한 값을 확인한 뒤 **가져오기**를 누르세요. 취소하면 편집 중이던 프로젝트로 돌아갑니다.
- 읽지 못한 타일 목록에는 레벨, 행·열, 총 칸 수가 표시됩니다. **목록 복사**로 가져오기 문제를 공유할 수 있습니다. 외부 JSON은 지원하는 구조와 타일 매핑이 필요합니다.
- 빈 맵은 **새 프로젝트**에서 시작합니다. 왼쪽 **Caves**에서 레벨을 추가하거나 번호·이름으로 찾습니다. **다른 번호로 저장**을 누르면 번호를 직접 지정할 수 있고, 이미 있는 번호는 덮어쓰기 확인이 뜹니다.

### 보드 편집

- 왼쪽에서 맵 크기, 중력, 클리어 목표와 **Moves**를 설정합니다. 별 점수, 수동 난이도, 오브젝트 생성 방식은 **레벨별 설정**에서 입력하고 **레벨 설정 적용**을 누릅니다.
- 오른쪽에서 **Terrain / Block / Gimmick / Item** 레이어를 선택한 뒤 **오브젝트 만들기**로 등록하거나, 가져온 오브젝트를 선택합니다. **브러시**로 클릭·드래그해 배치하고 **채우기**, **지우개**, **실행 취소**로 편집합니다.
- 셀에 마우스를 올리면 속성을 볼 수 있습니다. **칸 속성**으로 초기 특수 피스의 색·종류를 편집하거나 해제할 수 있습니다. **칸 비활성화**는 해당 칸을 보드에서 제외하며, 다시 누르면 빈 칸으로 복원합니다.
- 팔레트의 **사용처 보기**로 오브젝트가 쓰인 레벨과 위치를 확인할 수 있습니다. 사용 중인 종류를 삭제하려 하면 해당 사용처를 확인할 수 있습니다.

### 랜덤 생성

- 왼쪽 레벨 설정의 **랜덤 배치**에 시드와 밀도를 입력하고 **랜덤 채우기 · 시드로 블록 배치**를 누릅니다. 오른쪽 **사용 색상**에서 사용할 블록을 지정하세요.
- 같은 영역의 **보드 모양 후보**에서 모양을 골라 적용할 수 있습니다. **구역 아이템 랜덤 배치**는 행·열 범위, 아이템 종류, 개수를 받아 범위 안의 배치 가능한 빈 칸에 배치합니다. 먼저 오른쪽 **Item** 탭에 종류를 등록하세요.

### 플레이와 검증

- **Playtest**에서 인접한 블록 두 개를 선택해 교환하고, 클리어 목표와 남은 Moves를 확인합니다. 클리어 기록은 **이 기록을 난이도에 사용**으로 반영할 수 있습니다.
- **검증**은 현재 Cave를, **범위 검증**은 지정한 번호 범위를 자동으로 검사합니다. 자동 플레이의 클리어율과 Moves는 레벨 밸런스를 비교하는 참고 지표입니다.
- **Failure Bonus 사용**은 Cave의 설정값으로 저장됩니다. 현재 Playtest와 자동 검증에서는 이 값을 사용하지 않습니다. DDUNG 원본 JSON에는 해당 항목이 없습니다.

### 저장과 JSON 내보내기

- **저장**은 현재 브라우저에 작업을 저장합니다. 백업하거나 다른 기기에서 이어서 작업하려면 **전체 레벨 JSON으로 내보내기**를 사용하세요. 이 파일에는 레벨과 편집용 프로젝트 데이터가 함께 들어갑니다.
- **현재 레벨 JSON으로 내보내기**는 지원하는 원본 형식으로 현재 Cave 한 개를 내보냅니다. DDUNG 형식에서는 이동 횟수, 별 점수, 수동 난이도, 생성 방식의 변경을 지원합니다. 보드나 목표를 바꾼 작업은 전체 레벨 JSON으로 보관하세요. DDUNG 게임의 암호화된 MapInfo.txt는 별도 변환이 필요합니다.

### 콘텐츠 버전과 패치

- 기준 상태를 **전체 레벨 JSON으로 내보내기**로 보관합니다. 편집 후 상단 **CONTENT VERSION**을 직접 입력하거나 `− / +`로 바꿉니다. 예를 들어 기준이 `58`이면 수정본은 `59`로 지정합니다.
- **패치 내보내기**에서 기준 전체 JSON을 선택합니다. 미리보기에서 추가·수정·삭제된 Cave와 수정된 칸, 목표 및 Moves의 변경을 확인하고 **패치 다운로드**를 누릅니다. 검증 오류가 난 Cave는 미리보기에서 편집 화면으로 이동할 수 있습니다.
- 맵툴에서 패치 JSON을 가져오려면 현재 콘텐츠 버전이 패치의 `baseContentVersion`과 정확히 일치해야 합니다. 적용 후에는 `contentVersion`으로 갱신됩니다. `CLIENT`는 맵툴 코드 버전, `SCHEMA`는 JSON 구조 버전입니다.

## 로컬 실행

저장소 루트에서 정적 HTTP 서버를 실행합니다.

```bash
python -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.
