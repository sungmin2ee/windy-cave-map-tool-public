    맵툴 사용법

    시작하기
    • 기존 맵은 상단의 JSON 가져오기로 엽니다. 미리보기에서 레벨 수, 맵 크기, 특수 피스 종류, 읽지 못한 값을 확인한 뒤 가져오기를 누르세요. 취소하면 편집 중이던 프로젝트로 돌아갑니다.
    • 읽지 못한 타일 목록에는 레벨, 행·열, 총 칸 수가 표시됩니다. 목록 복사로 가져오기 문제를 공유할 수 있습니다. 외부 JSON은 지원하는 구조와 타일 매핑이 필요합니다.
    • 빈 맵은 새 프로젝트에서 시작합니다. 왼쪽 Caves에서 레벨을 추가하거나 번호·이름으로 찾습니다. 다른 번호로 저장을 누르면 번호를 직접 지정할 수 있고, 이미 있는 번호는 덮어쓰기 확인이 뜹니다.
    보드 편집
    • 왼쪽에서 맵 크기, 중력, 클리어 목표와 Moves를 설정합니다. 별 점수, 수동 난이도, 오브젝트 생성 방식은 레벨별 설정에서 입력하고 레벨 설정 적용을 누릅니다.
    • 오른쪽에서 Terrain / Block / Gimmick / Item 레이어를 선택한 뒤 오브젝트 만들기로 등록하거나, 가져온 오브젝트를 선택합니다. 브러시로 클릭·드래그해 배치하고 채우기, 지우개, 실행 취소로 편집합니다.
    • 셀에 마우스를 올리면 속성을 볼 수 있습니다. 칸 속성으로 초기 특수 피스의 색·종류를 편집하거나 해제할 수 있습니다. 칸 비활성화는 해당 칸을 보드에서 제외하며, 다시 누르면 빈 칸으로 복원합니다.
    • Gimmick 탭에는 새 프로젝트와 가져온 프로젝트 모두에서 Spawner가 기본으로 표시됩니다. 보드에 배치한 스포너는 지우개로 제거할 수 있습니다.
    • 팔레트의 사용처 보기로 오브젝트가 쓰인 레벨과 위치를 확인할 수 있습니다. 사용 중인 종류를 삭제하려 하면 해당 사용처를 확인할 수 있습니다.
    랜덤 생성
    • 왼쪽 레벨 설정의 랜덤 배치에 시드와 밀도를 입력하고 랜덤 채우기 · 시드로 블록 배치를 누릅니다. 오른쪽 사용 색상에서 사용할 블록을 지정하세요.
    • 같은 영역의 보드 모양 후보에서 모양을 골라 적용할 수 있습니다. 구역 아이템 랜덤 배치는 행·열 범위, 아이템 종류, 개수를 받아 범위 안의 배치 가능한 빈 칸에 배치합니다. 먼저 오른쪽 Item 탭에 종류를 등록하세요.
    • 왼쪽 랜덤 배치 → 난이도로 보드 생성에서 목표 난이도 1~100을 입력하고 후보 생성을 누릅니다. 사용 색상에 생성 가중치가 0보다 큰 블록이 두 종류 이상 필요합니다. Terrain 탭에는 매치로 제거할 수 있는 지형을 등록하고 반응 규칙을 설정하세요.
    • 생성된 보드의 클리어 목표는 Terrain 파괴입니다. 후보당 6회 자동 플레이를 돌려 한 번 이상 클리어한 보드 중 목표 난이도에 가까운 후보를 최대 3개 보여줍니다. 보드, 목표 수량, 제한 Moves, 추정 난이도와 클리어율을 확인하고 이 후보 적용을 누르세요.
    • 기존 오브젝트 배치 유지는 기본으로 켜져 있습니다. 기존 배치를 바탕으로 생성하려면 체크하고, 새로 배치하려면 체크를 해제하세요. 두 경우 모두 보드 크기와 비활성 칸을 유지합니다.
    • 자동 생성 시 스포너는 중력 반대쪽 가장자리에 배치됩니다. 중력이 아래면 위쪽, 위면 아래쪽, 왼쪽이면 오른쪽, 오른쪽이면 왼쪽입니다. 비활성 칸, 막힌 지형, 다른 기믹이 있는 칸은 건너뜁니다. 기존 오브젝트 배치 유지를 켜도 생성 후보의 스포너 위치는 이 규칙에 맞춰 조정됩니다.
    플레이와 검증
    • Playtest는 블록 교환과 특수 피스 발동을 자동으로 진행합니다. 일시정지 중에는 특수 피스를 클릭해 직접 발동할 수 있습니다. 발동에는 이동 1회를 사용합니다. 클리어 기록은 이 기록을 난이도에 사용으로 반영할 수 있습니다.
    • 매치로 특수 피스 생성을 켜면 가로·세로 4매치에서 해당 방향의 줄 폭탄, 5매치에서 같은 색 제거 피스, T/L자 매치에서 주변 3×3 폭탄이 생깁니다. DDUNG에서 가져온 레벨은 이 설정을 켜서 사용할 수 있습니다.
    • 칸 속성의 새 특수 타입 만들기에서 이름과 발동 효과를 선택합니다. 가로·세로 한 줄, 주변 3×3, 십자, 같은 색 전체 제거를 연결할 수 있습니다. 효과는 해당 Cave에서 같은 타입을 사용하는 피스에 적용됩니다.
    • 검증은 현재 Cave를, 범위 검증은 지정한 번호 범위를 자동으로 검사합니다. 자동 플레이의 클리어율과 Moves는 레벨 밸런스를 비교하는 참고 지표입니다.
    • Failure Bonus 사용은 Cave의 설정값으로 저장됩니다. 현재 Playtest와 자동 검증에서는 이 값을 사용하지 않습니다. DDUNG 원본 JSON에는 해당 항목이 없습니다.
    저장과 JSON 내보내기
    • 저장은 현재 브라우저에 작업을 저장합니다. 백업하거나 다른 기기에서 이어서 작업하려면 전체 레벨 JSON으로 내보내기를 사용하세요. 이 파일에는 레벨과 편집용 프로젝트 데이터가 함께 들어갑니다.
    • 현재 레벨 JSON으로 내보내기는 지원하는 원본 형식으로 현재 Cave 한 개를 내보냅니다. DDUNG 형식에서는 이동 횟수, 별 점수, 수동 난이도, 생성 방식의 변경을 지원합니다. 보드나 목표를 바꾼 작업은 전체 레벨 JSON으로 보관하세요. DDUNG 게임의 암호화된 MapInfo.txt는 별도 변환이 필요합니다.
    콘텐츠 버전과 패치
    • 기준 상태를 전체 레벨 JSON으로 내보내기로 보관합니다. 편집 후 상단 CONTENT VERSION을 직접 입력하거나 − / +로 바꿉니다. 예를 들어 기준이 58이면 수정본은 59로 지정합니다.
    • 패치 내보내기에서 기준 전체 JSON을 선택합니다. 미리보기에서 추가·수정·삭제된 Cave와 수정된 칸의 이전 값과 새 값, 목표 및 Moves의 변경을 확인합니다. 검증 오류가 난 Cave는 미리보기에서 편집 화면으로 이동할 수 있습니다.
    • 패치 다운로드를 누르면 변경분 JSON이 저장됩니다. 같은 기준으로 패치 미리보기로 다시 열면 마지막으로 보던 Cave 상세나 검증 오류에서 편집하러 이동한 Cave가 열립니다.
    • 맵툴에서 패치 JSON을 가져오려면 현재 콘텐츠 버전이 패치의 baseContentVersion과 정확히 일치해야 합니다. 적용 후에는 contentVersion으로 갱신됩니다. CLIENT는 맵툴 코드 버전, SCHEMA는 JSON 구조 버전입니다.
